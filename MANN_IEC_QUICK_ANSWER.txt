HOW MANN BOX ADAPTS TO COMPLEX TERRAIN
═══════════════════════════════════════════════════════════════════════════════

Mann Box has INHERENT advantages for complex terrain because it uses
a 3D anisotropic spectral tensor that can represent:

  ✓ Enhanced turbulence on windward slopes (acceleration)
  ✓ Reduced turbulence in lee zones (separation)
  ✓ Slope-aligned flow structure
  ✓ Spatial coherence changes with terrain

Implementation: Modify tensor parameters based on local slope/curvature:

    if (windward_slope) {
        // Flow acceleration enhances horizontal correlations
        L_u *= (1 + slope_acceleration_factor)
    }
    if (lee_zone) {
        // Flow separation reduces vertical coherence
        coherence_decay_vertical *= 1.5
    }


HOW IEC ADAPTS TO COMPLEX TERRAIN
═══════════════════════════════════════════════════════════════════════════════

IEC adapts more simply via terrain classification:

    if (terrain_class == "complex_forest") {
        I_ref = 0.18          // Higher intensity for rough terrain
        L_u = 350 m           // Longer correlations
    }
    else if (terrain_class == "flat_grassland") {
        I_ref = 0.12
        L_u = 250 m
    }

This captures the main effect: rougher terrain has higher turbulence
and longer correlations. Both effects are handled by lookup tables.

KEY ADVANTAGE: TERRAIN MASKING IS SHARED
═══════════════════════════════════════════════════════════════════════════════

The repository already has a sophisticated terrain-aware masking system:

    mask(z_agl) = {
        0.0,                        if z_agl ≤ 0          [inside terrain]
        (1 - cos(π·z_agl/h_t))/2,  if 0 < z_agl < h_t   [transition]
        1.0,                        if z_agl ≥ h_t        [free atmosphere]
    }

This means:
  ✓ Both Mann Box and IEC fluctuations can use the SAME masking
  ✓ No need to reinvent terrain handling
  ✓ Already proven to maintain mass conservation
  ✓ Already tested with complex terrain

This is the KEY to making unified implementation work!
