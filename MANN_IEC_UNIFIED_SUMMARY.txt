WHAT MUST BE SEPARATE? (Model-Specific)
════════════════════════════════════════════════════════════════════════════════

MANN BOX SPECIFIC:
  • 3x3 anisotropic spectral tensor S_ij(k⃗)
  • Eigenvalue decomposition and spatial coherence
  • Tensor parameter setup: σ_u, σ_v, σ_w, L_u, L_v, L_w, Γ
  • Tensor-based terrain modification (rotate/scale components)
  • Complex-valued spectral amplitudes
  • Terrain-induced anisotropy tensor adjustment

IEC 61400-1 SPECIFIC:
  • Parameter lookup tables by wind class (A, B, C)
  • Deterministic gust profiles (EOG, EWS, ECG)
  • Intensity scaling formulas from IEC standard
  • Simple coherence decay (v/u, w/u ratios)
  • Extreme event modeling capability
  • Category-based parameterization

HOW THEY WORK WITH COMPLEX TERRAIN
════════════════════════════════════════════════════════════════════════════════

MANN BOX ON COMPLEX TERRAIN:
─────────────────────────────
Inherent Advantages:
  • Spectral tensor captures terrain-induced anisotropy naturally
  • Can represent flow acceleration on ridges
  • Can represent flow deceleration in valleys
  • Properly models spatial coherence changes

Adaptation Mechanism:
  • Modify tensor components based on local terrain
  • Enhance L_u on windward slopes (acceleration)
  • Reduce L_u in lee (separation)
  • Rotate tensor for slope-aligned flow

Example Parameter Adjustment:
  L_u_modified = L_u × (1 + slope_acceleration_factor)
                     × (1 - confinement_factor)


IEC 61400-1 ON COMPLEX TERRAIN:
────────────────────────────────
Simpler Adaptation:
  • Use terrain classification to pick IEC parameters
  • Different table entry for forest vs. grassland
  • Different table entry for simple vs. complex terrain
  • Higher intensity for rough terrain

Example Parameter Selection:
  if (terrain_class == ForestComplex) {
      I_ref = 0.18          // Higher than grassland
      L_u = 350 m           // Longer correlation
  } else if (terrain_class == FlatGrassland) {
      I_ref = 0.12
      L_u = 250 m
  }

// ===== UNIFIED APPROACH =====

// Extended parameter structure (shared)
struct TurbulenceParams {
    bool enabled;
    TurbulenceModel spectrum_model;    // Mann, IEC, VonKarman, Kaimal
    IntensityModel intensity_model;
    CoherenceModel coherence_model;
    
    // NEW - Terrain awareness
    bool terrain_aware = true;
    TerrainClass terrain_class;
    
    // Model-specific parameters (discriminated union pattern)
    union {
        MannBoxParams mann_params;      // Mann-specific
        IECParams iec_params;           // IEC-specific
        // ... others
    } model_data;
};

// Main generation function (unified dispatcher)
void GenerateTurbulence(const TurbulenceParams& params, ...) {
    // Step 1: Shared terrain analysis
    auto z_agl = ComputeHeightAboveGround(terrain_height);
    auto terrain_class = ClassifyTerrain(slope, roughness, curvature);
    auto mask = ComputeTerrainMask(z_agl);
    
    // Step 2: Model-specific generation
    switch (params.spectrum_model) {
        case TurbulenceModel::Mann:
            GenerateMannBox(params.model_data.mann_params, z_agl, 
                          terrain_class, u', v', w');
            break;
        case TurbulenceModel::IEC:
            GenerateIEC(params.model_data.iec_params, z_agl,
                       terrain_class, u', v', w');
            break;
        // ... others
    }
    
    // Step 3: Shared masking and export
    ApplyTerrainMask(z_agl, u', v', w', mask);
    ExportToBTS(u', v', w');
}

KEY DESIGN DECISIONS
════════════════════════════════════════════════════════════════════════════════

1. USE DISCRIMINATED UNION (not inheritance)
   Reason: Cleaner for GPU code, better performance

2. SHARE TERRAIN MASKING FULLY (100%)
   Reason: Physics is identical, existing code works

3. SHARE TERRAIN CLASSIFICATION (100%)
   Reason: Both models benefit from terrain characterization

4. IMPLEMENT MODELS AS SEPARATE PATHS (not shared)
   Reason: Fundamentally different algorithms, easier to maintain

5. USE SAME BTS EXPORT (100%)
   Reason: Format is flexible enough, add metadata to distinguish

6. SUPPORT GPU FOR MANN BOX
   Reason: Tensor operations are expensive, worth GPU investment
