# Synthetic Turbulence Scenarios

This directory focuses on synthetic turbulence generation, anisotropic wind spectra, and dynamic atmospheric boundary layer simulations.

## Cases & Scripts

### 1. `mann_box/`
* **Purpose**: Advanced validation of the Mann Box anisotropic spectral tensor model.
* **Physics**:
  * Anisotropy ratios in spectral tensor components.
  * Realizability (Cauchy-Schwarz and positive semi-definiteness checks).
  * Spectral integrations and comparisons with Python references.
  * Spatial and temporal coherence of synthesized fluctuations.

### 2. `turbulence_enhancements/`
* **Purpose**: Verifies localized turbulence kinetic energy (TKE) enhancements and stability parameters.
