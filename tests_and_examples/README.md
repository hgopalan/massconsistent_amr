# Scenarios & Verification Cases

This directory contains categorized wind solver scenario cases, validation scenarios, verification studies, and tutorial configurations.

## Directory Structure

Cases are unified and structured into the following categories:

* **[buildings/](./buildings/)**: Urban structures, building-wake flow verification (Röckle, Huber-Snyder, AERMOD PRIME), and street canyon channeling.
* **[datacenter/](./datacenter/)**: Multi-facility data center heat island thermal plume analysis, buoyant plumes, and Briggs analytical comparisons.
* **[dispersion/](./dispersion/)**: Atmospheric puff and LPD dispersion simulations, agricultural drone spraying trajectory modeling, and PHREEQC geochemical coupling.
* **[physics/](./physics/)**: Cell-local anisotropy, complex terrain flow physics, spatially varying ABL height, and 3D wind assimilation.
* **[terrain/](./terrain/)**: Real and synthetic topography setups, including Gaussian hills, Mt. Hood (OR), and the Boulder Flatirons (CO).
* **[turbulence/](./turbulence/)**: Synthetic turbulence generation using Mann Box anisotropic spectral tensor models, spectrum validation, and integration tests.
* **[wakes/](./wakes/)**: Wind turbine analytical wake models (Jensen, Park), wake deflection under yaw, and IEC 61400-1 wind conditions.
