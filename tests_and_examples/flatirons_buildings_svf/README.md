# Flatirons Campus with Random Buildings and Sky View Factor

Test case demonstrating unified sky view factor (SVF) and solar shading computation with buildings on complex terrain.

## Location

Boulder, Colorado - Flatirons area (NREL test site coordinates)

## Features

1. **Real-world Terrain**: Synthetic Flatirons terrain with multiple ridges and valleys
2. **Random Campus Buildings**: 20 randomly generated buildings simulating university campus
3. **Unified SVF Computation**: Sky view factor from combined terrain+building elevation field
4. **Solar Shading**: Time-dependent shading based on solar position
5. **Diurnal Cycle**: Temperature and turbulence variation throughout the day

## Key Physical Processes

- **Sky View Factor (SVF)**: Computed from local terrain+building slope: SVF = (1 + cos(slope)) / 2
  - Accounts for horizon blocking by both terrain and buildings
  - Used to compute radiation transmission to surface

- **Solar Shading**: Ray-casting from sun position to check for blocking terrain/buildings
  - Varies with time of day (solar altitude and azimuth)
  - Automatically includes building shadows on street canyon floor

- **Terrain-Building Interaction**: Buildings treated as elevation features
  - No special casing required
  - Natural canyon effects emerge from slope analysis

## Files

- `test_flatirons_buildings_svf.py` - Generates synthetic terrain and buildings
- `inputs.i` - Wind solver configuration file
- `terrain.csv` - Terrain elevation data (generated by Python script)
- `buildings.csv` - Building geometry data (generated by Python script)

## Usage

### Step 1: Generate Test Data

```bash
cd tests_and_examples/flatirons_buildings_svf
python3 test_flatirons_buildings_svf.py
```

This creates:
- `terrain.csv` - 400 terrain points with Gaussian ridges
- `buildings.csv` - 20 randomly placed buildings

### Step 2: Run Wind Solver

```bash
/path/to/build/wind_solver inputs.i
```

Expected output:
- `plt_flatirons_buildings_svf_*` - AMReX plotfiles with wind field and diagnostic data

## Validation

The test validates:
1. SVF computation with complex terrain
2. Building shading during different solar positions
3. Urban canyon effects (street-level radiation reduction)
4. Terrain-building elevation field merging
5. Integration with full wind field solver
