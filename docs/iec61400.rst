IEC 61400-1 Wind Input Models
==============================

Overview
--------

This implementation adds support for **IEC 61400-1:2019 wind input models** for wind turbine design and certification. The module provides implementations of all five standard wind input models required for regulatory compliance:

- **NTM** — Normal Turbulence Model (continuous turbulence during normal operation)
- **ETM** — Extreme Turbulence Model (extreme turbulence conditions, 1-year recurrence)
- **EOG** — Extreme Operating Gust (single extreme gust event)
- **EWS** — Extreme Wind Shear (extreme vertical/horizontal wind shear)
- **ECG** — Extreme Coherent Gust (extreme gust with wind direction change)

These models are essential for wind turbine design load cases and certification according to the international IEC 61400-1 standard.

    CLASS_I:   Vref = 50.0 m/s,  Vavg = 10.0 m/s,  Iref = 0.18 (high wind resource sites)
    CLASS_II:  Vref = 42.5 m/s,  Vavg = 8.5 m/s,   Iref = 0.18 (medium wind resource sites)
    CLASS_III: Vref = 37.5 m/s,  Vavg = 7.5 m/s,   Iref = 0.18 (low wind resource sites)

.. note::

   Classes I-III are defined in IEC 61400-1:2019 Table 1. Class IV is **not** part of the official
   standard but is provided for very low wind resource sites with estimated parameters.
   For certification purposes, use only Classes I-III.

Model Details
-------------

Normal Turbulence Model (NTM)
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

The NTM defines the normal wind climate encountered during operational life of the turbine.

**Characteristics:**

* Continuous turbulent wind with varying intensity
* Turbulence intensity decreases with height
* Reference turbulence intensity: Iref = 0.18
* Defined for wind speeds from 0.5 × Vavg to Vref

**Turbulence Intensity Profile:**

The turbulence intensity at height z is calculated as:

.. math::

    I(z) = I_{ref} \cdot \left(\frac{0.2}{z / z_{ref}}\right)^{0.2}

where:
- Iref = 0.18 (reference turbulence intensity at 15 m)
- z = height above ground
- zref = 15 m (reference height)

**Wind Profile:**

Power-law profile:

.. math::

    U(z) = U_{ref} \cdot \left(\frac{z}{z_{ref}}\right)^{\alpha}

where α is the terrain-dependent shear exponent.

Extreme Turbulence Model (ETM)
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

The ETM defines a 1-year recurrence extreme turbulence condition.

**Characteristics:**

* Higher turbulence intensity than NTM (factor 1.4 at hub height)
* Represents severe turbulent wind conditions
* Applied at Vref wind speed
* Used for design load case calculations

**Turbulence Intensity:**

.. math::

    I_{ETM}(z) = 1.4 \cdot I_{NTM}(z)

Extreme Operating Gust (EOG)
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

The EOG represents a single extreme gust that may occur during operation.

**Characteristics:**

* Single transient gust superimposed on steady mean wind
* Gust duration: 10.5 seconds typical
* Time to peak gust: varies from 3-6 seconds
* Gust magnitude depends on wind speed
* Applied at operating wind speeds from 0.5 × Vavg to Vref

**Gust Shape:**

The gust profile uses a smooth ramp-up and exponential decay:

.. math::

    g(t) = \begin{cases}
    g_{peak} \cdot \frac{1}{2}(1 - \cos(\pi t / t_{peak})) & \text{for } t \leq t_{peak} \\
    g_{peak} \cdot \exp(-3(t - t_{peak}) / (T - t_{peak})) & \text{for } t > t_{peak}
    \end{cases}

where:
- gpeak = 2.5 × σ (σ depends on wind speed)
- tpeak = time to reach peak
- T = total duration

Extreme Wind Shear (EWS)
~~~~~~~~~~~~~~~~~~~~~~~~

The EWS defines extreme vertical or horizontal wind shear.

**Characteristics:**

* Extreme vertical shear: enhanced power-law exponent
* Extreme horizontal shear: lateral wind speed variation
* Applied at reference wind speed
* Vertical shear is most critical for turbines

**Vertical Shear Profile:**

The vertical shear uses an enhanced power-law with exponent:

.. math::

    \alpha_{EWS} = \alpha_{terrain} + 0.2

**Horizontal Shear:**

Lateral variation across rotor disk:

.. math::

    U(z) = U_{ref} \cdot (1 + 0.2 \sin(2\pi z / D))

where D is rotor diameter.

Extreme Coherent Gust (ECG)
~~~~~~~~~~~~~~~~~~~~~~~~~~~~

The ECG represents an extreme coherent gust combined with a wind direction change.

**Characteristics:**

* Extreme gust with simultaneous direction change
* Direction change: ±180° (front or back vortex pair)
* Gust duration: 10.5 seconds typical
* Most critical for structural loads and control systems

**Gust and Direction Change:**

Gust magnitude:

.. math::

    g_{peak} = 3.3 \cdot \sigma

Direction change profile (same temporal shape as gust):

.. math::

    \Delta\theta(t) = \Delta\theta_{max} \cdot \text{(same profile as gust)}

Python API
----------

Basic Usage
~~~~~~~~~~~

Create and use NTM model:

.. code-block:: python

    from iec61400_models import NormalTurbulenceModel
    import numpy as np
    
    # Create model for IEC Class II turbine
    ntm = NormalTurbulenceModel(
        turbine_class="II",
        terrain_category=1,
        z_hub=90.0
    )
    
    # Generate wind profile at multiple heights
    heights = np.array([10, 40, 90, 120])
    profile = ntm.generate_wind_profile(heights, mean_speed=8.5)
    
    print("Wind Speed Profile:")
    for h, v in zip(profile["heights"], profile["mean_wind_speed"]):
        print(f"  {h:6.1f} m: {v:6.2f} m/s")

Factory Function
~~~~~~~~~~~~~~~~

Create models using factory function:

.. code-block:: python

    from iec61400_models import create_iec_model
    
    # Create any model type
    ntm = create_iec_model("NTM", turbine_class="II", terrain_category=1)
    etm = create_iec_model("ETM", turbine_class="II", terrain_category=1)
    eog = create_iec_model("EOG", turbine_class="II", terrain_category=1)
    ews = create_iec_model("EWS", turbine_class="II", terrain_category=1)
    ecg = create_iec_model("ECG", turbine_class="II", terrain_category=1)

Turbulence Intensity
~~~~~~~~~~~~~~~~~~~~

Calculate turbulence intensity at any height:

.. code-block:: python

    ntm = NormalTurbulenceModel("II", terrain_category=1)
    
    # Turbulence intensity at hub height
    ti_90m = ntm.turbulence_intensity(90.0)
    print(f"Turbulence intensity at 90 m: {ti_90m:.2%}")
    
    # Profile across multiple heights
    heights = np.linspace(10, 150, 50)
    ti_profile = np.array([ntm.turbulence_intensity(h) for h in heights])

Wind Profiles
~~~~~~~~~~~~~

Generate wind speed profiles:

.. code-block:: python

    ntm = NormalTurbulenceModel("II", terrain_category=1)
    
    # Log-law profile
    heights = np.linspace(10, 150, 50)
    wind_log = ntm.log_law_profile(heights, reference_speed=8.5, reference_height=10.0)
    
    # Power-law profile
    wind_power = ntm.power_law_profile(heights, reference_speed=8.5, reference_height=10.0)

Generate gust profiles:

Coupling with Wind Solver
--------------------------

The IEC 61400-1 models can be used to generate boundary conditions for the mass-consistent wind solver:

**Example: Using NTM with Wind Solver**

.. code-block:: python

    from wind_solver import WindSolver
    from iec61400_models import NormalTurbulenceModel
    import numpy as np
    
    # Create NTM profile
    ntm = NormalTurbulenceModel("II", terrain_category=1, z_hub=90.0)
    heights = np.array([10, 90, 150])
    profile = ntm.generate_wind_profile(heights, mean_speed=8.5)
    
    # Use profile to initialize solver
    wind = WindSolver("inputs.i")
    
    # Update reference wind with IEC parameters
    wind.update_reference_wind(
        u_ref=8.5,
        v_ref=0.0,  # Nominal direction
        z_ref=10.0
    )
    
    wind.solve()
    velocity = wind.get_velocity()

**Example: EOG Load Case Analysis**

.. code-block:: python

    from iec61400_models import ExtremeOperatingGust
    from wind_solver import WindSolver
    
    # Create EOG model
    eog = ExtremeOperatingGust("II", terrain_category=1)
    
    # Generate gust profile
    gust = eog.generate_gust_profile(
        duration=10.0,
        time_to_peak=5.0,
        mean_speed=12.0,
        sampling_rate=10.0
    )
    
    # Create wind field snapshots during gust
    # (Can be used for transient load analysis)
    time = gust["time"]
    gust_profile = gust["gust_profile"]
    
    # Save for use in turbine simulation
    np.savetxt("eog_gust.csv", np.column_stack([time, gust_profile]))

Design Load Cases (DLC) Support
--------------------------------

The IEC 61400-1 models enable calculation of design load cases (DLC) as defined in the standard:

**DLC 1.1 — Normal Operation (NTM)**
- Wind speed range: 0.5 × Vavg to Vref
- Model: NormalTurbulenceModel
- Duration: 600-3600 seconds

**DLC 1.2 — Normal Operation with ETM**
- Wind speed: Vref
- Model: ExtremeTurbulenceModel
- Duration: 600-3600 seconds
- Turbulence: 1.4 × NTM

**DLC 2.1 — Power Production + EOG**
- Wind speed range: Vavg to Vref
- Model: ExtremeOperatingGust
- Number of gusts: At least 4 per wind speed bin

**DLC 2.2 — Power Production + EWS**
- Wind speed range: Vavg to Vref
- Model: ExtremeWindShear
- Positive and negative shear

**DLC 2.3 — Power Production + ECG**
- Wind speed: Vref
- Model: ExtremeCoherentGust
- Direction changes: ±180°
