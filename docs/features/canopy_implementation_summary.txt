================================================================================
MODELS IMPLEMENTED
================================================================================

1. MacDonald et al. (2000) - Displacement Height Model
   - Computes effective displacement height d and roughness z0_eff
   - Based on canopy morphology (λ_f, λ_p, C_d)
   - Formulas:
     * d/H = 1 + α^(-λ_p)(λ_p - 1),  α = 4.43
     * z0/H = (1-d/H)exp(-√(1/(0.5βC_d(1-d/H)λ_f))),  β = 1.0
   - Modified log-law: u(z) = (u*/κ)ln((z-d+z0)/z0)

2. Shaw & Pereira (1982) - Exponential Decay Model
   - Exponential wind decay within canopy (z < h)
   - Profile: u(z) = u(h)exp(-α(1-z/h))
   - Above canopy: log-law with displacement height
   - Typical α values: 2-4 (2.5 default)
