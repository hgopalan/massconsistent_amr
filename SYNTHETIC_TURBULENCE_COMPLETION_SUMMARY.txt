================================================================================
PHYSICS MODELS SUPPORTED
================================================================================

Spectral Models:
  - Von Kármán: S(f) = (4Lᵤσ²ᵤ)/(1 + 70.8(fLᵤ/U)²)^(5/6)
  - Kaimal: S(f) = (4Lᵤσ²ᵤ)/(1 + 5fLᵤ/U)²

Intensity Profiles:
  - PowerLaw: I(z) = I_ref * (z/z_ref)^α
  - Logarithmic: I(z) = I_ref * ln(z/z₀) / ln(z_ref/z₀)
  - Constant: I(z) = constant

Coherence Models:
  - Gaussian: ρ(Δy) = exp(-(k*Δy)²)
  - Exponential: ρ(Δy) = exp(-k*Δy)

Temporal Autocorrelation:
  - Exponential: ρ(τ) = exp(-|τ|/T_int)
  - Gaussian: ρ(τ) = exp(-(τ/T_int)²)

================================================================================
KNOWN LIMITATIONS & FUTURE WORK
================================================================================

Current Limitations:
  1. FFT grid size limited to power-of-2 for efficiency
  2. BTS export is primary format (netCDF/HDF5 planned)
  3. Spectral models limited to Von Kármán and Kaimal
  4. Single wind direction (no veer with height)

Possible Future Enhancements:
  1. Multi-scale turbulence (coherent structures)
  2. Wind veer and shear with height
  3. Stable/unstable stratification effects
  4. Wind farm coherent structures
  5. Extreme gust simulation
  6. Machine learning parameter optimization
  7. Real-time streaming BTS output
  8. Cloud computing integration
