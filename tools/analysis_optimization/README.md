# Analysis & Optimization Utilities

This directory contains utility scripts for parameter sensitivity sweeps and operational workflow optimizations.

## Utility Scripts

* **`mann_box_sensitivity_analysis.py`**: Sensitivity analyses of Mann Box parameters, assessing spectral realizability and shear impacts on coherence.
* **`drone_sensitivity_analysis.py`**: Sweeps drone agricultural puff spray parameters (droplet size distribution, evaporation, rotor downwash) for drift mitigation.
* **`weather_window_optimizer.py`**: Optimization tool that computes ideal agricultural flight windows based on local atmospheric stability.
* **`parameter_sensitivity.py`**: General sensitivity profiling for core wind solver parameters.
